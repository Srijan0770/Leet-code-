# Leet-code-

A repository containing solutions to LeetCode problems with implementations in various programming languages.

## Overview

This repository is a collection of solutions to LeetCode problems. Each solution includes clean, well-documented code with explanations of the approach and complexity analysis.

## Directory Structure

```
Leet-code-/
├── Easy/
├── Medium/
├── Hard/
└── README.md
```

## Problem Categories

- **Easy**: Beginner-friendly problems covering fundamental concepts
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems requiring optimization and advanced techniques

## How to Use

1. Navigate to the difficulty level folder
2. Find the problem you're interested in
3. Review the solution code and explanation
4. Run the code locally to test and verify

## Topics Covered

- Arrays & Strings
- Linked Lists
- Trees & Graphs
- Dynamic Programming
- Sorting & Searching
- Hash Tables
- Stacks & Queues
- And more...
